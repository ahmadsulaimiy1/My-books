# فهرس النصوص الشرعية: افتتاحية المجلد الأول

الآيات على ترتيب المصحف، والأحاديث والآثار على ترتيب أطرافها، مع مواضعها. الدليل، الجزء الحادي عشر (الباب ٧٩). يُولَّد من `pdf/registers.py`، ويُبنى منه فهرس المجلد عند إخراجه.

## أولًا: الآيات، على ترتيب المصحف

|---|---|---|

| البقرة: ٢٦٣ | ﴿قَوْلٌ مَّعْرُوفٌ وَمَغْفِرَةٌ خَيْرٌ مِّن صَدَقَةٍ يَتْبَعُهَآ…﴾ | ف٢ |
| النساء: ٦٣ | ﴿فَأَعْرِضْ عَنْهُمْ وَعِظْهُمْ وَقُل لَّهُمْ فِىٓ أَنفُسِهِمْ…﴾ | ف٢ |
| إبراهيم: ٤ | ﴿وَمَآ أَرْسَلْنَا مِن رَّسُولٍ إِلَّا بِلِسَانِ قَوْمِهِۦ…﴾ | ف١ |
| النحل: ١٢٥ | ﴿ٱدْعُ إِلَىٰ سَبِيلِ رَبِّكَ بِٱلْحِكْمَةِ وَٱلْمَوْعِظَةِ ٱلْحَسَنَةِۖ…﴾ | ف٢ |
| الإسراء: ٢٣ | ﴿فَلَا تَقُل لَّهُمَآ أُفٍّ وَلَا تَنْهَرْهُمَا وَقُل…﴾ | ف٢ |
| الإسراء: ٢٨ | ﴿وَإِمَّا تُعْرِضَنَّ عَنْهُمُ ٱبْتِغَآءَ رَحْمَةٍ مِّن رَّبِّكَ…﴾ | ف٢ |
| الإسراء: ٣٦ | ﴿وَلَا تَقْفُ مَا لَيْسَ لَكَ بِهِۦ عِلْمٌۚ…﴾ | ف٢ |
| الإسراء: ٥٣ | ﴿وَقُل لِّعِبَادِى يَقُولُوا۟ ٱلَّتِى هِىَ أَحْسَنُ﴾ | ف٢ |
| الكهف: ٦٤ | ﴿ذَٰلِكَ مَا كُنَّا نَبْغِ﴾ | ف٦ |
| طه: ٢٥–٢٨ | ﴿قَالَ رَبِّ ٱشْرَحْ لِى صَدْرِى ۝٢٥ وَيَسِّرْ…﴾ | ف١ |
| طه: ٤٤ | ﴿فَقُولَا لَهُۥ قَوْلًا لَّيِّنًا لَّعَلَّهُۥ يَتَذَكَّرُ أَوْ…﴾ | ف٢ |
| الشعراء: ١٩٣–١٩٥ | ﴿نَزَلَ بِهِ ٱلرُّوحُ ٱلْأَمِينُ ۝١٩٣ عَلَىٰ قَلْبِكَ…﴾ | ف١ |
| القصص: ٣٤ | ﴿رِدْءًا يُصَدِّقُنِىٓ﴾ | ف٨ |
| القصص: ٣٤ | ﴿وَأَخِى هَٰرُونُ هُوَ أَفْصَحُ مِنِّى لِسَانًا﴾ | ف٨ |
| القصص: ٣٤ | ﴿وَأَخِى هَٰرُونُ هُوَ أَفْصَحُ مِنِّى لِسَانًا فَأَرْسِلْهُ…﴾ | ف١ |
| لقمان: ١٩ | ﴿وَٱقْصِدْ فِى مَشْيِكَ وَٱغْضُضْ مِن صَوْتِكَۚ إِنَّ…﴾ | ف٢ |
| الأحزاب: ٧٠–٧١ | ﴿يَٰٓأَيُّهَا ٱلَّذِينَ ءَامَنُوا۟ ٱتَّقُوا۟ ٱللَّهَ وَقُولُوا۟ قَوْلًا…﴾ | ف٢ |
| الحجرات: ٦ | ﴿يَٰٓأَيُّهَا ٱلَّذِينَ ءَامَنُوٓا۟ إِن جَآءَكُمْ فَاسِقٌۢ بِنَبَإٍ…﴾ | ف٢ |
| ق: ١٨ | ﴿مَّا يَلْفِظُ مِن قَوْلٍ إِلَّا لَدَيْهِ رَقِيبٌ…﴾ | ف٢ |
| الرحمن: ١–٤ | ﴿ٱلرَّحْمَٰنُ ۝١ عَلَّمَ ٱلْقُرْءَانَ ۝٢ خَلَقَ ٱلْإِنسَٰنَ…﴾ | ف١ |
