# الدليل التحريري والعلمي — الجزء الثالث
## دليل الأمثلة، ونموذج المقارنة الثلاثية، ودليل الحوار، ودليل الأخطاء

---

## الباب السابع: دليل الأمثلة (Example Bible)

### ١. أنواع الأمثلة
| النوع | الطول | وظيفته |
|---|---|---|
| مثال قصير | كلمة إلى جملة | تثبيت القاعدة، التمييز السريع |
| مثال متوسط | ٢–٥ جمل | إظهار القاعدة في سياق |
| مثال ممتد | فقرة إلى صفحة | إظهار البناء (افتتاح، انتقال، خاتمة) |
| حوار | ٦–٤٠ سطرًا | إظهار التفاعل والمقام |
| نموذج كامل | محاضرة، خطبة، مقابلة، اجتماع | نموذج جاهز للاستعمال والتحليل |

وبحسب المجال: خطابي، أكاديمي، علمي شرعي، إداري، اجتماعي، أسري، إعلامي، دبلوماسي، جامعي — ونيجيري/إفريقي السياق عند الحاجة، وعربي السياق كذلك.

### ٢. سُلّم تدرج الأمثلة
```
بسيط  ←  متوسط  ←  متقدم  ←  احترافي  ←  ارتجالي
```

### ٣. الحدود الدنيا الكمية (تطبيق مبدأ الشمول) *(قرار معلّق رقم ٣)*
هذه حدود دنيا لا سقوف؛ ويُزاد عليها بحسب حاجة الموضوع.

| الوحدة | الحد الأدنى المقترح |
|---|---|
| كل مفهوم رئيسي | ١٠ أمثلة قصيرة + ٥ متوسطة + مثال ممتد واحد |
| كل مهارة أدائية (التعريف بالنفس، الافتتاح، الاعتذار…) | تطبيقها في **٢٠ مقامًا** على الأقل، ولكل مقام المقارنة المتدرجة |
| كل فصل | ٣ مقارنات ثلاثية مفصلة التحليل + حوار ممتد واحد مع نسخته المحسنة كاملة |
| كل فصل | ١١ نوعًا من التمارين (انظر الجزء الرابع)، و٥ بنود على الأقل لكل نوع |
| كل فصل | ١٠ سيناريوهات واقعية على الأقل (فيبلغ مجموعها في الكتاب مئات السيناريوهات) |
| كل بنك تعبيري | ٤٠ صيغة على الأقل، لكل صيغة: متى تُستعمل؟ ومتى لا تُستعمل؟ ودرجة رسميتها |
| كل خطأ في بنك الأخطاء | ٥ جمل تدريبية على الأقل لتثبيت النمط الصحيح |

### ٤. مصفوفة التنويع (إلزامية في كل فصل)
يُراجَع كل فصل على هذه المحاور، ويجب أن يغطي أربعة عناصر على الأقل من كل محور:

| المحور | عناصره |
|---|---|
| **المتحدث** | الشيخ، الأستاذ الجامعي، الخطيب، المذيع، المدير، الدبلوماسي، المعلم، الأب، الأم، الطالب، الباحث، المتحدث الرسمي |
| **المخاطَب** | شيخ، عالم، أستاذ، مدير، وزير، مسؤول، زميل، طالب، موظف، طفل، والد، والدة، ضيف، مريض، شخص لأول مرة، جمهور عام، جمهور متخصص |
| **المقام** | المسجد، الجامعة، المدرسة، المكتب، الاجتماع، المؤتمر، مجلس العلماء، المقابلة، الهاتف، الإذاعة، التلفاز، المنصة، الحفل، الزيارة، السفر، اللقاء الرسمي، اللقاء العائلي |
| **الرسمية** | ٥ شديد الرسمية، ٤ رسمي، ٣ شبه رسمي، ٢ ودي، ١ أسري |
| **الطول** | عبارة، جملة، ٣ جمل، ٣٠ ثانية، دقيقة، ٣ دقائق، ٥ دقائق |
| **الغرض** | تعريف، طلب، اعتذار، شكر، اعتراض، إخبار، إقناع، تهنئة، تعزية، إنهاء |

### ٥. التطبيقات الأربعة الإلزامية للمواقف المهمة
لكل موقف مهم يُعرض المعنى نفسه:
- **بحسب المتحدث** (الشيخ يقوله هكذا، والمدير هكذا، والمذيع هكذا…) مع بيان سبب الاختلاف.
- **بحسب المخاطَب** (لشيخ، لزميل، لطالب، لطفل…).
- **بحسب المقام** (في المسجد، في المكتب، على الهاتف…).
- **بحسب درجة الرسمية** (الخمس)، مع بيان متى تُستعمل كل صيغة.

### ٦. بطاقة المثال
كل مثال مهم يحمل رمزًا ثابتًا ليسهل الإحالة إليه في دليل المعلم وبنك الاختبارات:
```
[م٤-ب٥-ف٢-مث١٧]  = المجلد ٤ - الباب ٥ - الفصل ٢ - المثال ١٧
```
وفي بطاقة المثال: الرمز، بطاقة المقام (مختصرة)، النص، الدرجة (غير ناجح/مقبول/ناجح/رفيع)، ملاحظة المدرب.

### ٧. ما يُمنع في الأمثلة
- تكرار المثال نفسه بتغيير كلمة.
- الأمثلة المدرسية الميتة («ذهب زيدٌ إلى السوق») في مقام التدريب على الكلام الحي.
- أسماء أشخاص حقيقيين أحياء أو مؤسسات حقيقية في أمثلة الأخطاء.
- السخرية من لهجة أو قبيلة أو لغة.
- أمثلة سياسية أو خلافية طائفية لا تخدم الغرض التدريبي.

## الباب الثامن: نموذج المقارنة المتدرجة (العلامة المميزة للمشروع)

### ١. الدرجات *(قرار معلّق رقم ٤)*
| الدرجة | الاسم المعتمد | وصفها |
|---|---|---|
| ١ | **المتكلم غير الناجح** | النموذج كما يقع فيه المتعلم فعلًا: أخطاء لغوية أو مقامية أو أدبية تُفسد الغرض. |
| ٢ | **المتكلم المقبول** | لا أخطاء كبيرة، يؤدي الغرض، لكنه باهت، أو فيه ترجمة يسيرة، أو أطول أو أقصر مما ينبغي. |
| ٣ | **المتكلم الناجح** | عربي فصيح طبيعي مناسب للمقام، يحقق المعايير الخمسة. |
| ٤ | **المتكلم الرفيع** *(اختياري)* | الناجح مع لمسة بيان: حسن اختيار، أو إيجاز بليغ، أو شاهد في موضعه — **بلا تكلف**. يُستعمل في المواقف المهمة فقط. |

**التوصية:** المقارنة الثلاثية (١–٣) إلزامية في كل موضع، والرابعة للمواقف المحورية (التعريف بالنفس، الافتتاح، المقابلة، الخطبة، مخاطبة العلماء).

### ٢. قالب العرض
```
▣ بطاقة المقام: …

① المتكلم غير الناجح:
   «…»
② المتكلم المقبول:
   «…»
③ المتكلم الناجح:
   «…»
(④ المتكلم الرفيع:
   «…»)
```

### ٣. جدول تحليل الفروق (إلزامي بعد كل مقارنة)
لا يُكتفى بقول «هذا أفضل». يُملأ هذا الجدول (تُحذف الأبعاد التي لا فرق فيها):

| البعد | ① غير الناجح | ② المقبول | ③ الناجح |
|---|---|---|---|
| اللغة والنحو | | | |
| المفردات | | | |
| الأسلوب (طبيعي/مترجم/متكلف) | | | |
| النبرة | | | |
| ترتيب الأفكار | | | |
| مقدار الكلام | | | |
| الأدب | | | |
| ملاءمة المقام | | | |
| الوضوح | | | |
| الطلاقة | | | |
| التأثير | | | |

ثم ثلاثة أسئلة: لماذا أخفق الأول؟ لماذا قُبل الثاني ولم يبلغ الغاية؟ ما الذي جعل الثالث ناجحًا؟

### ٤. نموذج تطبيقي للقالب (للتوضيح)
▣ **المتكلم:** خريج ماجستير · **المخاطَب:** لجنة مقابلة في معهد للغة العربية · **الرسمية:** ٤ · **الغرض:** التعريف بالنفس · **الزمن:** ٣٠ ثانية

① **غير الناجح:**
«إييه… بسم الله… أنا اسمي عبد الرحمن، أنا جئت من كانو، أنا متخرج من الجامعة، أنا عندي ماجستير، وأنا أحب العربية جدًّا جدًّا، وإن شاء الله أنا سأعطي أفضل ما عندي، وشكرًا.»

② **المقبول:**
«بسم الله الرحمن الرحيم. اسمي عبد الرحمن، من مدينة كانو. تخرجت في قسم اللغة العربية، وحصلت على الماجستير في النحو. أحب التدريس، وأرجو أن أكون مفيدًا لهذا المعهد.»

③ **الناجح:**
«السلام عليكم ورحمة الله. أشكر لكم إتاحة هذه الفرصة. أنا عبد الرحمن، مدرّس لغة عربية من كانو، أحمل الماجستير في النحو، ودرّستُ ثلاث سنوات في المرحلة الثانوية. تقدمت إلى معهدكم لأن برنامجه يُعنى بتعليم الكلام، وهو ما أُحسنه وأحبه.»

| البعد | ① | ② | ③ |
|---|---|---|---|
| الافتتاح | بسملة بعد تردد، بلا سلام | بسملة، بلا سلام ولا شكر | سلام وشكر في جملتين |
| الحشو | «إييه»، تكرار «أنا» ست مرات | لا حشو | لا حشو |
| المعلومات | عامة («متخرج من الجامعة») | محددة جزئيًا | محددة: التخصص، الخبرة بالسنوات |
| الصلة بالمقام | معدومة | عامة («مفيدًا للمعهد») | مباشرة: سبب اختيار هذا المعهد |
| الأسلوب | «سأعطي أفضل ما عندي» ترجمة لـ *give my best* | طبيعي | طبيعي |
| الخاتمة | «وشكرًا» مبتورة | مقبولة | تنتهي بما يربطه بالوظيفة |

*(الاسم والمدينة للتمثيل؛ الشخص افتراضي.)*

## الباب التاسع: دليل الحوار (Dialogue Bible)

### ١. قواعد كتابة الحوار
1. **تسبقه بطاقة المقام** دائمًا.
2. **الأسطر مرقّمة** ليحيل إليها التحليل: (س٧) = السطر السابع.
3. **أسماء الشخصيات** افتراضية، وتُذكر الصفة معها أول مرة: «الشيخ إبراهيم (رئيس المجلس)».
4. **إرشادات الأداء** بين معقوفين، موجزة، بوزن خفيف ولون الغرافيتي في الإخراج (**لا بخط مائل**؛ فالحرف العربي لا يُمال صناعيًا — انظر الجزء السادس، الباب ٢٦): [بصوت خافت]، [يبتسم]، [يتوقف لحظة].
5. **الحوار حيّ**: فيه عند الحاجة سؤال، وجواب، واستيضاح، وتردد طبيعي، واعتراض، وإعادة صياغة، واعتذار، وتصحيح، وانتقال، وخاتمة.
6. **لكل شخصية لسانها**: الشيخ غير الطالب، والمدير غير الموظف؛ ولا تتكلم الشخصيات كلها بصوت المؤلف.
7. **التردد الطبيعي** يُكتب باعتدال («أقصد…»، «عفوًا، أعني…») ولا يُحوَّل إلى سخرية.
8. **الطول بحسب المقام**: حوار موقف اجتماعي ٦–١٢ سطرًا؛ مقابلة وظيفية كاملة ٣٠–٦٠ سطرًا.

### ٢. بنية الحوار التعليمي الكامل (إلزامية في الحوار الممتد)
```
١. بطاقة المقام
٢. الحوار الأول (كما يقع — فيه أخطاء المتعلم)
٣. التحليل سطرًا سطرًا، بالأسئلة:
   - لماذا نجحت البداية أو أخفقت؟
   - ما العبارة المناسبة؟ وما التي كان ينبغي تجنبها؟
   - كيف كانت النبرة؟
   - هل كان الجواب طويلًا أو مختصرًا أكثر من اللازم؟
   - هل أجاب عن السؤال أم ابتعد عنه؟
   - هل ظهرت الثقة أم الغرور أم الضعف؟
   - هل الأسلوب طبيعي؟ هل فيه أثر ترجمة حرفية؟
٤. النسخة المحسنة — كاملة لا مقتطعة
٥. جدول «ماذا تغيّر؟» (السطر، قبل، بعد، السبب)
٦. تمرين: أدِّ الحوار في ثنائي، ثم بدّل أحد عناصر المقام وأعد الأداء
```

## الباب العاشر: دليل الأخطاء (Error Bible)

### ١. التصنيف الموحد ورموزه
| الرمز | الصنف | مثال مختصر |
|---|---|---|
| خ-١ | صوتي (مخرج الحرف) | ض تُنطق قريبة من اللام أو الدال |
| خ-٢ | نطقي أدائي (حركات، مدود، تشديد) | قصر المد في «قال» فتصير «قَلَ» |
| خ-٣ | نحوي | «رأيت المعلمون» |
| خ-٤ | صرفي | جمع «كتاب» على «كُتوب» بدل «كُتُب» |
| خ-٥ | معجمي | لفظ صحيح في غير معناه |
| خ-٦ | تركيبي | ترتيب غير عربي للجملة |
| خ-٧ | أسلوبي | تكلف، حشو، غريب |
| خ-٨ | بلاغي | تشبيه في غير موضعه، سجع متكلف |
| خ-٩ | تداولي | صيغة أمر حيث يُنتظر طلب مهذب |
| خ-١٠ | مقامي | أسلوب ودي في مقام رسمي أو العكس |
| خ-١١ | اجتماعي | مقاطعة، تقدم على الكبير |
| خ-١٢ | ثقافي | نقل عادة تعبيرية محلية لا تُفهم عربيًا |
| خ-١٣ | السرعة | إسراع يضيع المعنى، أو بطء يقتل الانتباه |
| خ-١٤ | النبرة | رتابة، أو صراخ، أو نبرة استعلاء |
| خ-١٥ | الوقف | وقف يفسد المعنى أو وصل يخلطه |
| خ-١٦ | الترجمة الحرفية | «أخذ مكانًا» (*take place*) بمعنى «وقع/جرى» |
| خ-١٧ | أخطاء المستعربين الخاصة | أثر النظام الصوتي أو النحوي للغة الأم |
| خ-١٨ | أخطاء المقابلات | الإجابة عن غير المسؤول عنه |
| خ-١٩ | أخطاء المجالس العلمية | التصحيح الفظ للشيخ |
| خ-٢٠ | أخطاء الخطابة والإعلام | الخروج عن الوقت، الإطالة، سوء الانتقال |

### ٢. درجات الخطورة
| الدرجة | الاسم | التعريف |
|---|---|---|
| ● | **قاتل** | يغير المعنى في القرآن أو الذكر، أو يُسقط المتكلم في مقام مهم (مثل «إنشاء الله»). |
| ◐ | **مغيّر للمعنى** | يؤدي إلى فهم غير المراد. |
| ◔ | **لافت** | لا يغير المعنى لكنه يلفت سمع العربي ويُضعف الانطباع. |
| ○ | **هنة** | خلاف الأولى أو الأفصح. |

### ٣. بطاقة الخطأ (القالب الموحد)
```
الرمز: خ-… | الخطورة: … | المستوى الذي يعالَج فيه: م…
الخطأ:             «…»
التصحيح:           «…»
التعليل:           لماذا هو خطأ؟
كيف يحدث؟          سبب محتمل (بصيغة غير تعميمية)
كيف يسمعه العربي؟   الانطباع أو سوء الفهم الذي يسببه
البديل الطبيعي:     كيف يقولها العربي الفصيح بسلاسة؟
التدريب:           خمس جمل على الأقل لتثبيت النمط
```

### ٤. ثلاث بطاقات نموذجية

**البطاقة (أ)**
الرمز: خ-٢ / خ-١٧ | الخطورة: ● قاتل | م١
- **الخطأ:** «إنشاء الله» (بوصل النون بالشين والهمزة المكسورة الواحدة).
- **التصحيح:** «إنْ شاءَ اللهُ» — ثلاث كلمات: أداة الشرط «إنْ»، والفعل «شاءَ»، ولفظ الجلالة.
- **التعليل:** «إنشاء» مصدر بمعنى الإيجاد والتأليف، فيضيع معنى التعليق بالمشيئة. والخطأ في النطق أظهر منه في الكتابة، لكنه يقع فيهما.
- **كيف يحدث؟** قد يقع عند بعض المتعلمين لسرعة الأداء، ولأن العبارة تُحفظ سماعًا كتلة واحدة.
- **كيف يسمعه العربي؟** يلحظ غياب السكون على نون «إنْ» وقِصَر الألف في «شاءَ».
- **البديل الطبيعي:** «إنْ شاءَ اللهُ» بسكون النون، ومدّ الألف مدًّا واضحًا، وتفخيم لام الجلالة بعد الفتح.
- **التدريب:** «سأحضرُ غدًا إنْ شاءَ الله.» / «نلتقي بعدَ الصلاةِ إنْ شاءَ الله.» / «إنْ شاءَ اللهُ يكونُ خيرًا.» / «سأُنهي البحثَ هذا الشهرَ إنْ شاءَ الله.» / «قولوا: إنْ شاءَ الله، ولا تستعجلوا.»

**البطاقة (ب)**
الرمز: خ-١٦ | الخطورة: ◔ لافت | م٢
- **الخطأ:** «سأعطي محاضرة عن الزكاة.» / «سأعطي أفضل ما عندي.»
- **التصحيح:** «سألقي محاضرة عن الزكاة.» / «سأبذل قصارى جهدي.» أو «سأبذل وسعي.»
- **التعليل:** ترجمة حرفية لـ *give a lecture* و*give my best*؛ والعربية تقول «ألقى محاضرة» و«بذل جهده».
- **كيف يحدث؟** قد يظهر عند بعض المتعلمين المتأثرين بالإنجليزية لغةً للتعليم الرسمي.
- **كيف يسمعه العربي؟** يفهم المعنى، لكنه يشعر أن الجملة «مترجمة».
- **البديل الطبيعي:** «يسعدني أن ألقي عليكم محاضرة…»، «سأحرص على أن أقدّم أفضل ما أستطيع.»
- **التدريب:** خمس جمل تحويلية من *give a talk / give advice / give a speech / give attention / give an example* إلى: «ألقى كلمة، نصح/أسدى نصيحة، ألقى خطبة، انتبه/أولى عناية، ضرب مثلًا».

**البطاقة (ج)**
الرمز: خ-١ / خ-١٧ | الخطورة: ◐ مغيّر للمعنى أحيانًا | م١
- **الخطأ:** نطق الضاد قريبة من اللام أو الدال أو الظاء، فيُسمع «رمضان» مثلًا بصوت غير الضاد. *(يُلاحظ أن الكلمة دخلت بعض اللغات الإفريقية بصيغة محلية؛ والمطلوب في الكلام العربي الفصيح النطق العربي لا الصيغة المقترَضة.)*
- **التصحيح:** الضاد بمخرجها وصفاتها في النطق المعتمد في المشروع *(انظر القرار المعلّق رقم ٨ بشأن معيار نطق الضاد)*.
- **التعليل:** الضاد ليست في النظام الصوتي الأصلي لكثير من اللغات، فيقربها المتعلم من أقرب صوت في لغته.
- **كيف يحدث؟** قد يظهر عند بعض المتعلمين تبعًا لخلفيتهم اللغوية؛ ولا يُنسب إلى لغة بعينها إلا بعد مراجعة المختص الصوتي في لجنة المراجعة.
- **كيف يسمعه العربي؟** قد يلتبس «ضلّ» بـ«ظلّ» أو «دلّ».
- **التدريب:** أزواج دنيا: ضلّ/دلّ/ظلّ، ضرب/درب، فضل/فصل، أرض/أرز — ثم جمل: «في رمضانَ فضلٌ عظيم»، «ضاق الوقتُ فاختصرْ»، …
