# الدليل التحريري والعلمي — الجزء الخامس
## دليل الأسلوب، ودليل المصطلحات، وبنية الكتاب والمجلدات، وضبط الجودة، وقاعدة الشمول

## الباب الخامس عشر: دليل الأسلوب (Style Bible)

### ١. روح اللغة
فصيحة، رصينة، واضحة، جميلة، أكاديمية، معاصرة، عربية الروح، بعيدة عن التكلف، وبعيدة عن الأسلوب النمطي للذكاء الاصطناعي.

### ٢. المقاييس
| العنصر | القاعدة |
|---|---|
| **الفقرة** | فكرة واحدة؛ لا تزيد في الغالب على ٥ أسطر (نحو ٨٠ كلمة) في المتن الشارح. |
| **الجملة** | الغالب ١٢–٢٥ كلمة؛ تُقسم الجملة التي تتجاوز ٣٥ كلمة. |
| **العناوين** | خمسة مستويات: الجزء (المجلد) ← الباب ← الفصل ← الوحدة ← الدرس؛ وتحتها عناوين وظيفية ثابتة (الموقف، القاعدة، الأمثلة…). لا عنوان بلا محتوى تحته. |
| **الترقيم** | علامات الترقيم العربية: ، ؛ ؟ — والتنصيص بـ«»، والتنصيص الداخلي بـ"". النقطتان قبل القول والتفصيل. علامة الحذف …. |
| **الأرقام** | *(قرار معلّق رقم ٧)*: المقترح الأرقام المشرقية (١٢٣) في المتن، والعربية الغربية (123) في ترقيم الآيات والأحاديث إذا اقتضت الطبعة المرجعية ذلك. |
| **الشكل (التشكيل)** | شكل تام: الآيات، الأحاديث، الشعر، نصوص التدريب الصوتي، النماذج المعدّة للإلقاء. شكل ما يُشكِل: المتن الشارح. شكل أواخر الكلمات: الحوارات المعدة للأداء *(قرار معلّق رقم ٦)*. |
| **المصطلح الأجنبي** | يُذكر بين قوسين عند أول وروده فقط، إن كان يفيد المدرب: «السجل اللغوي (Register)». لا يُكتب بحروف عربية («الريجستر»). |
| **التعريف** | في إطار مستقل: «**تعريف:** …». جملة واحدة إلى جملتين، ثم شرح. |
| **التنبيه** | «**تنبيه:** …» لخطأ متوقع. |
| **الفائدة** | «**فائدة:** …» لمعلومة إثرائية غير أساسية. |
| **ملاحظة المدرب** | «**للمدرب:** …» — تُجمع كذلك في دليل المعلم. |
| **القاعدة** | في إطار بارز، بصياغة قصيرة قابلة للحفظ. |
| **الأمثلة** | مرقمة برموزها؛ الصحيح يسبقه ✔، والخاطئ ✘، والمقبول ◐. |
| **الحوارات** | وفق دليل الحوار (أسطر مرقمة، إرشادات أداء بين معقوفين). |
| **التمارين** | تكليف بفعل أمر واضح، ثم البنود مرقمة، ثم مفتاح الإجابة في دليل المعلم (لا في كتاب الطالب إلا للتقييم الذاتي). |
| **الجداول** | لا تزيد على ٦ أعمدة في كتاب الطالب؛ عنوان للجدول؛ ولا جدول لمعلومة تكفيها جملة. |
| **الإخراج البصري** | يحكمه الجزء السادس (دليل الهوية البصرية والإخراج الفني): الحروف، والألوان، والعناصر التعليمية، والأغلفة، والصور. ولا ميل ولا تسطير في النص العربي المطبوع؛ والمائل في ملفات الدليل نفسها للتمييز في المسودة فقط. |
| **الشواهد** | آية ← حديث ← أثر ← قول عالم ← شعر ← مثل؛ بحسب دليل التوثيق. |

### ٣. عبارات ممنوعة أو مقيدة (أسلوب نمطي يُتجنب)
| تُجتنب | السبب / البديل |
|---|---|
| «في عالمنا المتسارع اليوم…» | افتتاح مستهلك؛ ابدأ بالموقف. |
| «لا شك أن…»، «مما لا ريب فيه…» في كل فقرة | تأكيد فارغ؛ قرّر المعنى مباشرة. |
| «تجدر الإشارة إلى أن…» (الإكثار) | مرة في الفصل على الأكثر. |
| «يلعب دورًا» | «له أثر في…»، «يُسهم في…». |
| «رحلة»، «بوابة»، «مفتاح النجاح» (مجازات مستهلكة) | الوصف المباشر. |
| «في هذا الفصل سوف نستعرض…» ثم إعادة القائمة | الأهداف السلوكية تكفي. |
| الثلاثيات المتكلفة المتكررة (واضحًا، شاملًا، متكاملًا) | صفة واحدة دقيقة. |
| التكرار بألفاظ مختلفة | قُل الفكرة مرة واحدة ثم انتقل إلى المثال. |
| السجع المتكلف في المتن | يُقبل إن جاء عفوًا، ولا يُطلب. |

## الباب السادس عشر: دليل المصطلحات (Terminology Bible)

لا يتغير المصطلح من فصل إلى فصل. أي تغيير يُسجَّل في «سجل التغييرات» مع سببه.

| المصطلح المعتمد | التعريف المعتمد | لا يُستعمل بدله |
|---|---|---|
| **المتكلم الناجح** | من حقق كلامه المعايير الخمسة في مقام معين. | المتكلم الجيد، المتحدث الممتاز |
| **المتكلم غير الناجح** | من أخفق كلامه في تحقيق غرضه في مقام معين. | المتكلم الفاشل *(يُذكر مرة واحدة في المقدمة لبيان سبب العدول عنه)* |
| **المتكلم المقبول** | من أدى الغرض بلا أخطاء كبيرة ولم يبلغ النجاح. | المتوسط |
| **المتكلم الرفيع** | الناجح مع لمسة بيان بلا تكلف. | الممتاز، المتميز، البليغ *(إلا في سياق بلاغي)* |
| **المعايير الخمسة** | الوضوح، الصحة، المناسبة، التأثير، الأدب. | — |
| **الملكة الشفهية** | قدرة راسخة على إنتاج الكلام المناسب تلقائيًا. | المهارة الكلامية العامة، القدرة اللغوية |
| **الفصاحة** | سلامة اللفظ والتركيب من العيوب، وخلوصهما من الغرابة والتعقيد. | — |
| **البلاغة** | مطابقة الكلام الفصيح لمقتضى الحال. | الفصاحة *(لا يُخلط بينهما)* |
| **البيان** | الكشف عن المعنى وإيصاله إلى السامع (بالمعنى العام عند الجاحظ). | — |
| **المقام** | مجموع ظروف الكلام: المكان والزمان والمناسبة والعلاقة. | الموقف *(يُستعمل «الموقف» للقصة التدريبية المحددة)* |
| **الموقف** | حالة تدريبية محددة بأشخاصها ومكانها. | السيناريو *(يُستعمل «السيناريو» في بنك المواقف فقط)* |
| **المخاطَب** | من يوجَّه إليه الكلام (بفتح الطاء). | المستمع *(المستمع أعم)* |
| **السجل اللغوي** | مستوى الاستعمال بحسب المقام (أكاديمي، إداري…). | المستوى اللغوي *(يُخص «المستوى» بمستويات البرنامج)* |
| **درجة الرسمية** | موضع الكلام على السلّم الخماسي. | — |
| **التعبير الطبيعي** | ما يقوله العربي الفصيح تلقائيًا في المقام. | التعبير السليم *(السلامة غير الطبيعية)* |
| **الترجمة الحرفية** | نقل تركيب لغة أخرى إلى العربية كلمةً بكلمة. | — |
| **التكلف** | تجاوز الطبيعي إلى المصطنع في اللفظ أو الأداء. | التقعر *(التقعر نوع من التكلف)* |
| **الطلاقة** | اتصال الكلام بلا تردد مخلّ ولا حشو صوتي. | السرعة |
| **الحشو الصوتي** | أصوات ملء الفراغ («إييه»، «يعني»…). | — |
| **الارتجال** | الكلام في مقام لم يُستعد له إلا ثواني. | — |
| **المحاكاة** | أداء موقف واقعي بأدوار محددة. | لعب الأدوار |
| **التدريب الموجّه** | تدريب مقيد بنموذج أو قالب. | — |
| **التدريب الحر** | تدريب يُنتج فيه المتعلم كلامه دون قالب. | — |
| **بطاقة المقام** | الإطار الإلزامي فوق كل نموذج مهم. | — |
| **النموذج السداسي** | من، لمن، ماذا، لماذا، أين ومتى، كيف. | — |
| **مستوى البرنامج** | مرحلة من المستويات ٠–١٢. | — |
| **الأصوات الحرجة** | الأصوات التي يكثر فيها الخطأ عند المستعربين. | الحروف الصعبة |

## الباب السابع عشر: بنية الكتاب والمجلدات (Book Architecture Bible)

### ١. التسلسل الهرمي
```
الجزء (المجلد) ← الباب ← الفصل ← الوحدة ← الدرس ← التدريب ← المحاكاة ← التقييم
```
- **الجزء** يقابل مرحلة من مراحل البرنامج.
- **الباب** يقابل مستوى من مستويات البرنامج (٠–١٢).
- **الفصل** مهارة كبرى.
- **الوحدة** جانب من المهارة (مثلًا: التعريف بالنفس في المقامات الرسمية).
- **الدرس** حصة تدريبية (٩٠ دقيقة تقريبًا) بالقالب الموحد.

*(تعديل عن المسودة السابقة: ما سُمّي «القسم» في «خريطة الكتاب» يصير «الباب»، وتُعاد تسمية الخريطة بعد الاعتماد.)*

### ٢. المجلدات المقترحة *(قرار معلّق رقم ٥)*

**كتاب الطالب — أربعة مجلدات:**
| المجلد | العنوان | الأبواب (المستويات) | الحجم التقديري |
|---|---|---|---|
| الأول | التأسيس: الأسس، واللسان، والعبارة | ٠، ١، ٢ | ٤٠٠–٥٠٠ صفحة |
| الثاني | التواصل: البيان، والمقام، والأدب | ٣، ٤، ٥ | ٤٥٠–٥٥٠ صفحة |
| الثالث | المنصات: الحوار، والمجالس، والمنبر، والمؤسسة | ٦، ٧، ٨، ٩ | ٤٥٠–٥٥٠ صفحة |
| الرابع | التمكين: الإعلام، والدبلوماسية، والملكة، وبنك الأخطاء | ١٠، ١١، ١٢ + بنك الأخطاء | ٤٠٠–٥٠٠ صفحة |

*(الأحجام تقديرية؛ يحكمها مبدأ الشمول لا رقم مسبق.)*

**الكتب المرافقة:**
| الكتاب | محتواه |
|---|---|
| **المكتبة التعبيرية** (مجلد مرجعي) | البنوك التعبيرية كلها: التحيات، التعريف بالنفس، افتتاح المحاضرات والاجتماعات، مخاطبة العلماء، الاستئذان، السؤال، طلب المساعدة، الاعتذار، الشكر، الاعتراض المؤدب، الاختلاف العلمي، الرد على النقد، الرفض بأدب، التهنئة، التعزية، الانتقال، التوضيح، الاستدراك، التلخيص، التأكيد، التلطيف، التعليق، الخواتيم، إنهاء الحديث — لكل صيغة: متى تُستعمل ومتى لا تُستعمل ودرجة رسميتها. |
| **دليل المعلم** | أهداف كل درس، زمن الأنشطة، طريقة إدارتها، الأخطاء المتوقعة، مفاتيح الإجابات، نماذج التقييم. |
| **كتاب التدريبات** | تمارين إضافية بالأنواع الإحدى عشرة لكل درس. |
| **كتاب الصوتيات** | نصوص التدريب الصوتي المشكولة برموز الأداء، وبرنامج نطق يومي (٣٠ يومًا)، مع تسجيلات مرجعية. |
| **بنك المواقف** | مئات السيناريوهات مصنفة بحسب المقام والمخاطب والغرض والرسمية والمستوى. |
| **بنك الاختبارات** | اختبار تحديد المستوى، اختبارات الدروس والمستويات، مهام مشروع التخرج. |
| **كتاب النماذج الكاملة** | محاضرات، خطب، دروس، مقابلات، اجتماعات، مداخلات، تقديم مؤتمر، خطاب رسمي، لقاء إعلامي، زيارة عالم — كاملة جاهزة للاستعمال. |
| **سكريبتات الحلقات** | نصوص حلقات البرنامج التدريبي المرئي/المسموع، وملخص صوتي لدقيقتين لكل درس. |

## الباب الثامن عشر: ضبط الجودة (Quality-Control Bible)

### ١. المراجعات الإحدى عشرة (لا يُعتمد فصل قبلها)
| # | المراجعة | يتولاها (لجنة افتراضية في مرحلة الكتابة، وبشرية عند الإخراج) | السؤال الحاكم |
|---|---|---|---|
| ١ | علمية | عالم لغة عربية | هل المعلومة صحيحة؟ |
| ٢ | لغوية | لغوي/مدقق | هل النص سليم نحوًا وصرفًا وضبطًا؟ |
| ٣ | بلاغية | أستاذ بلاغة | هل النماذج «الناجحة» ناجحة فعلًا بلاغيًا؟ |
| ٤ | تربوية | مصمم مناهج | هل يمكن تدريسه وقياسه؟ هل القالب مكتمل؟ |
| ٥ | ثقافية | المراجع النيجيري/الإفريقي | هل يناسب البيئة؟ هل فيه تعميم أو جرح؟ |
| ٦ | الأمثلة | مدرب تواصل | هل الأمثلة كافية ومتنوعة وواقعية؟ هل استُوفيت الحدود الدنيا ومصفوفة التنويع؟ |
| ٧ | المصادر | محقق | هل كل اقتباس موثق؟ هل أُزيلت الوسوم أو بقيت ظاهرة لما لم يُتحقق منه؟ |
| ٨ | مستوى الصعوبة | أستاذ تعليم العربية للناطقين بغيرها | هل يناسب المستوى؟ هل التدرج سليم؟ |
| ٩ | الاتساق الاصطلاحي | المحرر | هل المصطلحات وفق دليل المصطلحات؟ |
| ١٠ | التحرير النهائي | رئيس التحرير | هل التزم الفصل بالدليل كله؟ |
| ١١ | بصرية وإخراجية | المخرج الفني | هل اجتازت الصفحات «اختبار الريادة» ومصفوفة التباين وميزانية اللون وإيقاع التنفس؟ (الجزء السادس، الباب ٢٨) |

*(لا تُنسب آراء اللجنة الافتراضية إلى علماء حقيقيين.)*

### ٢. أسئلة الاعتماد الخمسة عشر
هل هو علمي؟ صحيح لغويًا؟ مؤصل؟ عملي؟ يمكن تدريسه؟ يمكن تقييمه؟ فيه أمثلة كافية؟ يعالج أخطاء واقعية؟ يناسب المستعرب؟ يناسب الطالب الجامعي؟ يناسب الشيخ والمعلم؟ يحسّن أداء المتعلم فعلًا؟ يختلف عن كتب التعبير التقليدية؟ يستطيع المدرب استعماله مباشرة؟ يستطيع المتعلم تطبيقه خارج الفصل؟
**إن كان جواب أيٍّ منها «لا» أُعيد تطوير الفصل.**

### ٣. سجل اعتماد الفصل (يُرفق بكل فصل)
```
الفصل: … | الإصدار: … | التاريخ: …
[ ] المراجعات الإحدى عشرة   [ ] أسئلة الاعتماد   [ ] الحدود الدنيا للأمثلة
[ ] مصفوفة التنويع     [ ] الأفعال العشرة    [ ] الوسوم التوثيقية معالجة
ملاحظات: …                                  الحالة: مسودة / قيد المراجعة / معتمد
```

## الباب التاسع عشر: قاعدة الشمول (ملزمة)
- لا يُختصر المحتوى لمجرد الاختصار.
- إذا احتاج الموضوع عشرات الأمثلة أُعطيت عشرات الأمثلة؛ وإذا احتاج مئات المواقف على امتداد الكتاب أُنشئت مئات المواقف؛ وإذا احتاج حوارات طويلة كُتبت كاملة؛ وإذا احتاج مقارنة عشرات الأساليب عُرضت.
- ولا حشو: **كل مثال يؤدي وظيفة تعليمية واضحة**، ويُسأل عنه: ماذا يضيف مما لم يضفه ما قبله؟ (سياقًا جديدًا، أو مخاطبًا جديدًا، أو درجة رسمية، أو طولًا، أو غرضًا، أو خطأً مختلفًا). فإن لم يضف شيئًا حُذف.
- ولأن الإنتاج سيكون على دفعات، **يُكتب الفصل الواحد في عدة أجزاء عند الحاجة** بدل ضغطه في جزء واحد.

## الباب العشرون: ما بعد الدليل
لا تبدأ كتابة الكتاب قبل اعتماد هذا الدليل. انظر «الفهرس والقرارات المعلّقة» لما يحتاج إلى اعتماد صاحب المشروع.
