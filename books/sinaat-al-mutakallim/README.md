## قواعد ثابتة للمشروع

1. **لا اقتباس بلا مصدر، ولا مصدر مخترع.** ما لم يُتحقق من رقم صفحته يوسم بعبارة: «يحتاج إلى تحقق من المصدر».
2. **يُفصَل** بين: النص الأصلي، والاقتباس، والتلخيص، والاستنباط، والتحليل الحديث.
3. **الأسماء في الحوارات أسماء افتراضية** للتمثيل التدريبي، لا تشير إلى أشخاص حقيقيين.
4. **لا تعميم على الشعوب واللغات**: يُكتب «قد يظهر عند بعض المتعلمين…»، ولا سخرية من لهجة أو لغة أم.
5. **كل مفهوم يتبعه تطبيق، وكل تطبيق يتبعه تدريب قابل للقياس.**
6. مصطلح «المتكلم غير الناجح» (وهو «المتكلم الفاشل» في فكرة البرنامج الأولى) مصطلح تدريبي معناه: **كلامٌ لم يحقق غرضه**، لا حكمٌ على شخص المتعلم؛ ويُعتمد «غير الناجح» في المتن وفق دليل المصطلحات.

## طريقة المتابعة

بعد اعتماد الدليل، تُطلب الفصول بالترتيب من الخريطة، بأوامر مثل:
- «اكتب الفصل الأول من الباب الأول بالقالب المعتمد.»
- «ضع بطاقات الأخطاء التي قد تظهر عند بعض المتعلمين المتأثرين بالهوسا أو اليوربا أو الإنجليزية، وفق دليل الأخطاء.»
- «اكتب سكريبت حلقة: كيف تخاطب شيخًا في مجلس علم؟»
- «اكتب نماذج مقابلات وظيفية بالمقارنة الثلاثية: غير ناجحة، ومقبولة، وناجحة.»

## توليد ملف PDF

الملف الرسمي يُولَّد من ملفات Markdown في `bible/` والمسودات المُدخلة، بأداة `pdf/`:

```bash
python3 books/sinaat-al-mutakallim/pdf/build.py            # توليد الملف
python3 books/sinaat-al-mutakallim/pdf/build.py --review   # مع صفحات مصغّرة وتقرير للمراجعة الصفحية
```

والكتاب نفسه:

```bash
python3 books/sinaat-al-mutakallim/pdf/volume.py N      # المجلد N كاملًا (النسخة النهائية؛ و--review لنسخة المراجعة)
python3 books/sinaat-al-mutakallim/pdf/preflight.py N   # فحص ما قبل الطبع وصفحاته المتقابلة
python3 books/sinaat-al-mutakallim/pdf/series.py        # الفهرس العام من الخريطة المعتمدة (volumes.py)
python3 books/sinaat-al-mutakallim/pdf/ids.py           # سجلّ معرّفات الأمثلة: الإنتاجي والمطبوع
python3 books/sinaat-al-mutakallim/pdf/premove.py --strict   # بوابة البنية: لا يمرّ ما بقي أثرٌ للبنية القديمة
```

وأداة بناء المجلدات الأحد عشر وأغلفتها تُكتب على البنية النهائية حين يبدأ بناؤها (سجلّ الأدوات)؛ وأدوات الطبعة ذات الأجزاء الأربعة في الأرشيف. وتحتاج الأغلفة إلى `numpy` و`uharfbuzz`.

المتطلبات: Python 3.9 فأحدث مع `markdown` و`beautifulsoup4` و`pypdf` و`fonttools` و`brotli` (ومعها `pypdfium2` و`Pillow` للمراجعة)، وNode.js مع `playwright` ومتصفح Chromium. وتُنزَّل الخطوط (بترخيص SIL OFL) مرة واحدة إلى `pdf/.cache/`.
ويتوقف التوليد إذا جاورت نقطةٌ وسطى رقمًا مشرقيًا، أو دخل الملفَّ خطٌّ غير معتمد، أو تغيّر ترقيم الصفحات بين مرحلتي الإخراج.
